## Recent updates

### GitHub Copilot

- **Copilot in Slack (new):** GitHub Copilot now has a refreshed experience inside Slack — create issues, get PR summaries, and ask questions without leaving your chat. ([Changelog, Aug 21](https://github.blog/changelog/2026-08-21-the-new-github-copilot-experience-in-slack))
- **Shared agentic work in Microsoft Teams:** Teams users can now collaborate on Copilot agentic tasks together. ([Changelog, Aug 21](https://github.blog/changelog/2026-08-21-shared-agentic-work-with-github-copilot-in-microsoft-teams))
- **Copilot for Beginners — Managing your work:** A practical guide to using Copilot to organise tasks and issues. Good starting point for new users. ([GitHub Blog, Aug 19](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-managing-your-work/))
- **Agentic workflows with canvases:** Canvases give you a visual, steerable view into what Copilot agents are doing, making long-running tasks easier to follow and cheaper to run. ([GitHub Blog, Aug 17](https://github.blog/ai-and-ml/github-copilot/how-canvases-make-agentic-workflows-visible-steerable-and-cost-efficient/))

### GitHub Actions

- **Windows 11 arm64 with VS 2026 image GA:** The `windows-11-arm64` runner image now includes Visual Studio 2026 and is generally available. Update your workflows if you target Windows on ARM. ([Changelog, Aug 20](https://github.blog/changelog/2026-08-20-windows-11-arm64-vs2026-image-generally-available))
- **Separate Actions path for GitHub Code Quality:** Code Quality checks now run on a dedicated Actions path, keeping security scanning separate from your CI builds. ([Changelog, Aug 20](https://github.blog/changelog/2026-08-20-separate-github-actions-path-for-github-code-quality))

### Security & code scanning

- **Mitigated alert dismissal reason:** Code scanning alerts can now be dismissed with a "mitigated" reason, making it easier to track alerts that were addressed outside the tool. ([Changelog, Aug 20](https://github.blog/changelog/2026-08-20-code-scanning-adds-a-mitigated-alert-dismissal-reason))
- **Audit log for Code Quality enablement:** Changes to GitHub Code Quality settings are now recorded in the audit log. ([Changelog, Aug 20](https://github.blog/changelog/2026-08-20-track-github-code-quality-enablement-changes-in-the-audit-log))

### Projects & issues

- **Pin saved views to repository sidebar (GA):** You can now pin project views and milestones directly to the repository issues sidebar for quick access. ([Changelog, Aug 20](https://github.blog/changelog/2026-08-20-pin-projects-views-and-milestones-to-the-repository-sidebar))
